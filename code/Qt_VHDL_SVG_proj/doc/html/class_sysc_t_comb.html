Detailed Description

template<unsigned int W = 1>
class SyscTComb< W >

The SyscTComb::sc_core::sc_module template class.

A generic SystemC template module that implements a combinational block with N inputs of Win bits each (called d0, d1, etc.) and a single Wout-bits output called y. The modeled circuit is combinational, i.e., the output is updated whenever any of the inputs changes.
