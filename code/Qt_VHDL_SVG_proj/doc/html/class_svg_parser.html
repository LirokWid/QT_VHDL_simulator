Detailed Description

The SvgParser class.

This class parses an SVG file and extracts electrical links from attributes of SVG elements.

◆ parse_one_element()

void SvgParser::parse_one_element ( const QDomElement  svg_group_xml,
s_elements &  elements 
)
private

Parses a single SVG element and extracts information related to the device type, name, label, inputs, and outputs. Adds the parsed element to the provided list of elements.

Parameters
svg_group_xmlThe QDomElement representing the SVG element to be parsed.
elementsReference to the structure where parsed elements will be stored.

On an element, we should have the following attributes:

  • device: the type of the component
  • label : the schematic name of the component
  • inputs: the list of inputs -> d0:1:IN0,d1:1:IN1 (d0:1:IN0 means input 0, width 1, connected to IN0)
  • outputs: the list of outputs -> d0:1,d1:1
