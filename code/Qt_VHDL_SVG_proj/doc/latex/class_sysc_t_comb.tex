class Sysc\+TComb$<$ W $>$}
The Sysc\+TComb\+::sc\+\_\+core\+::sc\+\_\+module template class. 

A generic SystemC template module that implements a combinational block with N inputs of Win bits each (called d0, d1, etc.) and a single Wout-\/bits output called y. The modeled circuit is combinational, \doxylink{class_sysc_t_and_a1c3a6c18242880ceec6b31abc38f33a7}{i.\+e}., the output is updated whenever any of the inputs changes.
