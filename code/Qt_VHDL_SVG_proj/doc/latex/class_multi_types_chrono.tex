\doxysubsection{Detailed Description}
A custom Qt widget for visualizing and interacting with time-\/series data of various numeric types. 

This widget supports displaying boolean, integer, float, and double data in a graphical format. It allows users to zoom, pan, and fit data to view a specified range of values effectively. The widget features dynamic data point updates, popup information display on mouse hover, and adjustable visible range through a slider control.


\begin{DoxyTemplParams}{Template Parameters}
{\em T} & The type of data to be visualized. Supported types include bool, int, float, and double.\\
\hline
\end{DoxyTemplParams}
The widget includes the following features\+:
\begin{DoxyItemize}
\item Graphical rendering of data points with interactive features.
\item Customizable y-\/axis and x-\/axis scaling and labeling.
\item Display of statistics such as the type of data and the number of data points.
\item Ability to dynamically adjust the visible range of data through buttons and a slider.
\item Popup display that shows the step index and value of the data point under the mouse cursor.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Some features may require further enhancement, such as adding y-\/axis steps and visibility corrections 
\end{DoxyNote}
