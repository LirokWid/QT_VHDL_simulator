\doxysubsection{Detailed Description}
The \doxylink{class_svg_widget}{Svg\+Widget} class allows for loading, viewing, and interacting with SVG files using Qt\textquotesingle{}s graphics framework. 

The class provides functions to load an SVG, apply zoom, highlight elements, and modify styles of specific elements in the SVG.
