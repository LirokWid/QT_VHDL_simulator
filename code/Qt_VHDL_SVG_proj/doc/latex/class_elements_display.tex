\doxysubsection{Detailed Description}
A widget that displays parsed information from an SVG file in a tree structure. 

This class manages the display of components, simulation I/\+Os, and simulation wires from an SVG file. It organizes the data in a QTree\+Widget and supports interaction via mouse clicks to signal element selections.
