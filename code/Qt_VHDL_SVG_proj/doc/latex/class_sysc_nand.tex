class Sysc\+Nand$<$ N, W $>$}
The \doxylink{class_sysc_nand}{Sysc\+Nand} class. 

A generic SystemC module that implements a NAND gate with N inputs and 1 output. The gate is combinational, \doxylink{class_sysc_t_and_a1c3a6c18242880ceec6b31abc38f33a7}{i.\+e}., the output is updated whenever any of the inputs changes.
